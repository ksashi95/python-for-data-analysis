# 07 — Data Visualization

## Goal
Learn to communicate analytical results clearly with Python visualizations.

## Matplotlib
- Bar charts
- Line charts
- Scatter plots
- Histograms
- Box plots
- Titles and labels
- Legends
- Figure sizing

## Seaborn
- Bar plots
- Count plots
- Histograms
- Box plots
- Scatter plots
- Line plots
- Heatmaps

## Chart Selection
| Analytical question | Useful chart |
|---|---|
| Compare categories | Bar chart |
| Show a trend over time | Line chart |
| Show a distribution | Histogram |
| Show a relationship | Scatter plot |
| Examine spread and outliers | Box plot |
| Examine correlations | Heatmap |

## Practice
Create charts from the datasets used in earlier sections rather than learning visualization in isolation.

## Completion Goal
You should be able to choose an appropriate chart, create it, label it clearly, and explain the insight it communicates.
