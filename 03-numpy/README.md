# 03 — NumPy

## Goal
Learn the NumPy concepts that support numerical analysis and Pandas.

## What to Learn
1. NumPy arrays
2. Dimensions and shape
3. Data types
4. Indexing
5. Slicing
6. Vectorized operations
7. Basic numerical aggregation
8. `np.array()`
9. `np.mean()`
10. `np.median()`
11. `np.sum()`
12. `np.min()`
13. `np.max()`
14. `np.std()`

## Practice
- Create arrays
- Inspect shape and dimensions
- Select and slice values
- Perform calculations without explicit loops
- Calculate basic statistics

## Completion Goal
You should understand arrays and basic numerical operations well enough to support Pandas-based analysis.
