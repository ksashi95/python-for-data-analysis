# 02 — Python for Working With Data

## Goal
Learn how Python works with files, libraries, dates, and data-analysis objects.

## What to Learn
1. Importing libraries
2. File paths
3. CSV files
4. Excel files
5. Dates and basic date handling
6. Basic error handling
7. Understanding Python objects
8. Series and DataFrame concepts

## Practice
- Load a CSV file
- Load an Excel file
- Work with file paths
- Inspect basic Python objects
- Work with dates

## Completion Goal
You should understand how data enters Python and how Python represents data before starting NumPy and Pandas in depth.
