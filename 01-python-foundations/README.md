# 01 — Python Foundations

## Goal
Build the Python basics needed for data analysis.

## What to Learn
1. Python syntax and basic concepts
2. Variables
3. Operators
4. Data types
5. Type conversion
6. Strings
7. Lists
8. Tuples
9. Dictionaries
10. Sets
11. Conditional statements
12. `for` loops
13. `while` loops
14. Functions
15. Basic list comprehensions

## Practice
- Small calculations
- Working with lists and dictionaries
- Filtering values with conditions
- Repeating tasks with loops
- Writing simple reusable functions

## Completion Goal
You should be comfortable reading and writing basic Python code before moving to NumPy and Pandas.
